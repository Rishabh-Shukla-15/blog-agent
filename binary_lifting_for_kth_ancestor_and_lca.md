# Binary Lifting for Kth Ancestor and LCA
## Introduction to Binary Lifting
Binary lifting is a technique used in graph algorithms to efficiently find the kth ancestor of a node or the lowest common ancestor (LCA) of two nodes. 
* The definition of binary lifting refers to the process of precomputing and storing the ancestors of a node at increasing distances, typically powers of 2, to facilitate fast querying.
* Binary lifting is used in graph algorithms, such as finding the kth ancestor of a node or the LCA of two nodes, by leveraging the precomputed ancestor information to reduce the number of steps required to traverse the graph.
* The advantages of binary lifting include improved query efficiency, reduced time complexity, and enhanced scalability, making it a valuable technique in various graph-based applications, particularly those involving hierarchical or tree-like structures.

## Kth Ancestor Problem

* The **definition of Kth ancestor problem** states that given a tree and a node, we need to find the ancestor of the node that is K levels above it.
* A **naive approach to solve Kth ancestor problem** would be to traverse the tree from the given node up to the root, counting the number of levels until we reach the Kth ancestor. However, this approach can be inefficient for large trees and large values of K.
* An **optimized approach using binary lifting** can be employed to solve the Kth ancestor problem more efficiently. Binary lifting is a technique that allows us to quickly move up the tree by powers of 2, making it ideal for finding the Kth ancestor. By using binary lifting, we can reduce the time complexity of the problem and find the Kth ancestor in logarithmic time. This approach is particularly useful when dealing with very large trees and values of K.

## LCA Problem

* The LCA problem can be defined as: given a tree and two nodes, find the node that is farthest from the root and is an ancestor of both nodes.
* A naive approach to solve the LCA problem is to traverse the tree from the root node to the destination nodes and find the common ancestor. However, this approach can be time-consuming and inefficient, especially for large trees.
* An optimized approach to solve the LCA problem is by using binary lifting. Binary lifting is a technique used to quickly find the ancestor of a node at a given distance. By precomputing the ancestors of each node at powers of 2, we can quickly find the LCA of two nodes by iteratively moving up the tree and finding the common ancestor. This approach reduces the time complexity of the LCA problem from O(n) to O(log n), making it much more efficient for large trees.

## Binary Lifting Algorithm
The binary lifting algorithm is a technique used to find the Kth ancestor of a node and the Lowest Common Ancestor (LCA) in a tree. This algorithm is efficient and scalable, making it suitable for large trees. 
* The preprocessing step for binary lifting involves creating a 2D array, `up`, where `up[i][j]` represents the 2^jth ancestor of node `i`. This is done by iterating over all nodes and for each node, calculating its 2^jth ancestor by using the previously computed 2^(j-1)th ancestor.
* The query step for binary lifting involves finding the Kth ancestor of a node by using the `up` array. This is done by iterating over the bits of `K` from most significant to least significant and moving up the tree by using the `up` array.
* The time and space complexity of binary lifting are O(n log n) and O(n log n) respectively, where n is the number of nodes in the tree. This is because we need to store the `up` array and the preprocessing step takes O(n log n) time.
